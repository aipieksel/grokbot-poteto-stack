# Trust curve

The source notes attribute this progression to Lauren Tan (@poteto): start with one local agent and inspect its work; add project-specific verification; turn recurring failures into maintained instructions; evaluate those instructions; only then increase parallelism or cloud execution. This document summarizes that pattern, not a verified quotation or installation guarantee. The package does not bundle pstack. Confirm current installation and commands in the publisher's documentation before using the [Cursor adapter](../adapters/cursor-pstack.md).
